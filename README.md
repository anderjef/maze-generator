# Maze Generator

Maze Generator is a programmer-customizable random maze generator that relies on initially randomly walking (slower, harder-maze generation) until a set fraction of the cells have been generated, then switching to generation via depth-first backtracking (faster, easier-maze generation).  
Start date: 2020-10-28

## Installation

Open the repository with the editor of your choice, or skip installation altogether by visiting [the deployed version](https://anderjef.github.io/Maze_Generator/).

### Configuration

The variables to configure can be found at the top of [Maze_Generator.js](./Maze_Generator.js).

| Configuration | Description |
| ------------- | ----------- |
| `squareSize` | The side length in pixels of the squares (or cells) of the maze. |
| `showProgress` | Whether to show the maze-generation process, including console output. |
| `difficulty` | The fraction of squares (or cells) generated by random walk. Clamped to the mathematical range `[0, 1]`. |

## Usage

You can visit the production build which runs with 50%-difficulty at <https://anderjef.github.io/Maze_Generator/> or, if you have gone through the [installation](#installation), render [index.html](./index.html).
